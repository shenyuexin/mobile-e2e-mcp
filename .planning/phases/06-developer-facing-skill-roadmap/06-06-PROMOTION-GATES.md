# Phase 06 Plan 06 Promotion Gates

## Do not create real skill files until all gates pass

1. **Validation gate**
   - The lane has at least one frozen RED/GREEN acceptance card.

2. **Boundary gate**
   - The lane has a clear invocation boundary relative to baseline and other platform skills.

3. **Source-of-truth gate**
   - The future canonical source location is repo-tracked, not local-only.

4. **Scope honesty gate**
   - The skill remains focused on readiness, debugging, evidence interpretation, and remediation.

5. **Phase independence gate**
   - Skill publication planning remains distinct from Phase 05 release acceptance.

## Promotion Outcome

If all gates pass, a later slice may create real skill files.

If any gate fails, stay in planning and do not create `SKILL.md` files yet.
