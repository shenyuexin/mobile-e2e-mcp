# Phase 13 Plan 01

## Objective

- **What:** Remove iOS dependency on deprecated `idb` (fb-idb) by introducing a native backend router using `xcrun simctl` (simulators) and `xcrun devicectl` (physical devices), with Maestro as explicit fallback.
- **Why:** `idb` is unmaintained by Facebook, creating iOS compatibility risk. Apple's `xcrun` toolchain is official, stable, and ships with Xcode. This design also avoids deepening Maestro dependency for iOS simulator paths.
- **Output:** New backend abstraction layer (command builders matching UiRuntimePlatformHooks semantics), simctl/devicectl implementations, updated runtime hooks, and deprecation path for idb.

### Backend Selection Logic

```
1. 环境变量显式指定
   IOS_EXECUTION_BACKEND=simctl|devicectl|maestro|idb
   ├─ "idb" → 显示弃用警告，但仍工作
   └─ 无效值 → 抛出 ConfigurationError

2. 自动检测 (环境变量未设置时)
   if (isIosSimulatorId(deviceId)) → simctl backend
   if (isIosPhysicalDeviceId(deviceId)) → devicectl backend

3. 可用性探测回退
   For simulators:
     simctl available? → use simctl
     ↓ no
     throw ConfigurationError (simulators require simctl)

   For physical devices:
     devicectl available? → use devicectl (UI interactions via Maestro)
     ↓ no
     maestro available? → use maestro
     ↓ no
     throw ConfigurationError
```

### Key Design Decisions (含评审修正)

| Decision | Rationale | Review Feedback | Action Taken |
|---|---|---|---|
| `xcrun simctl` for simulators | Apple official, ships with Xcode, backward compatible | ✅ Approved | No change |
| `xcrun devicectl` for physical | Xcode 14+, no external deps, JSON output | ⚠️ Still uses Maestro for UI | Explicitly documented in plan |
| Backend interface = command builders | Matches UiRuntimePlatformHooks semantics | 🔴 Critical fix | Changed from execution to command builders |
| Maestro as fallback only | Avoids deepening dependency | ⚠️ Physical path still depends on Maestro | Honest labeling in capability model |
| Factory + test hooks for router | Testable singleton | 🔴 Critical fix | Added setBackendForTesting/resetForTesting |
| Environment variable control | Enables gradual migration, A/B testing, rollback | ✅ Approved | No change |
| No breaking changes | Existing users can migrate at their pace | ✅ Approved | No change |

        swipe: "full" | "partial" | "none";

        screenshot: "full" | "partial" | "none";
      };

      // Error suggestions
      buildFailureSuggestion(action: string, deviceId: string): string;
    }

    export interface BackendProbeResult {
      available: boolean;
      version?: string;  // e.g., "15.0" for Xcode version
