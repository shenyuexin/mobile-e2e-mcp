# Phase 06 Plan 11

## Goal

### Problem
Canonical skills now exist in-repo, but there is no repo-tracked installation/export layer that makes them practical to use without manual copying.

### Expected Outcome
- [x] A minimal explicit export layer exists.
- [x] `skills/` remains the only canonical source of truth.

### Non-goals
- Auto-writing to hidden local skill directories by default.
- Packaging skills for npm or any external distribution channel.

## Strategy

Implement the smallest useful layer: one export library, one CLI, one focused test file, and one usage section in `skills/README.md`.
