# Phase 06 Plan 13

## Goal

### Problem
The first-wave skills had pressure-test evidence, but Oracle still identified a remaining credibility gap: repeatable, repo-derived validation on messy workflow prompts.

### Expected Outcome
- [x] The first-wave skills are validated against repo-derived prompts instead of only author-shaped scenarios.
- [x] The resulting evidence is durable inside `.planning`.

### Non-goals
- Adding new skill families.
- Reworking the export layer.

## Strategy

Use showcase docs and bug-packet language to build a bounded real-workflow validation pack, then compare guided answers with lightweight controls on the hardest prompts.
