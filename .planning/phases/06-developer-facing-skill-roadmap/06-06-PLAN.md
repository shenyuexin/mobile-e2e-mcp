# Phase 06 Plan 06

## Goal

### Problem
Phase 06 now has validated readiness drafts with meaningful RED/GREEN evidence, but there is still no explicit publication-prep plan describing how those drafts would later become canonical real skill files without skipping repo-tracked source control, TDD-for-skills discipline, or rollout sequencing.

### Expected Outcome
- [ ] The planning workspace contains a concrete publication-prep spec for turning validated readiness drafts into future real skill files.
- [ ] Future real-skill publication now has a locked rollout order, file/source-of-truth strategy, and promotion gates.

### Non-goals
- Creating any real skill files.
- Installing or exporting skills into local skill directories.
- Changing public docs or support-boundary claims.

## Plan

### Strategy
Treat publication as a separate downstream step from validation. First define the canonical source layout, rollout order, TDD-for-skills prerequisites, and promotion gates in-repo under `.planning`. Only after those are explicit should any future slice create actual skill files.

### Task Breakdown
1. Lock the candidate publication set and rollout order.
2. Define the future canonical source location and target file inventory for real skill publication.
3. Freeze TDD-for-skills publication prerequisites using the validated RED/GREEN scenarios.
4. Record promotion gates and rollback/defer rules so later execution can publish safely.

### Risks / Unknowns
- Repo-tracked canonical skill sources may need a dedicated future directory decision before implementation.
- Publication can still fail later if skill frontmatter, discoverability wording, or local installation/export mechanics are under-specified.
- Phase 05 release acceptance remains unrelated but can still distract future execution if state updates blur the difference.
