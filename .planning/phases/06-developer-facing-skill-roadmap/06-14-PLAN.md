# Phase 06 Plan 14

## Goal

### Problem
Exportability alone did not prove runtime usefulness. The remaining gap was whether installed canonical skills were actually discoverable by the live OpenCode skill runtime.

### Expected Outcome
- [x] Installed first-wave skills are present in the local OpenCode skill root.
- [x] The `skill` tool can discover and return the installed baseline, Android, and iOS skills.

### Non-goals
- Publishing beyond the local OpenCode runtime.
- Adding more skill families.

## Strategy

Use the new install-target layer to install the first-wave skills into `~/.config/opencode/skills`, then prove runtime discoverability by loading each skill through the `skill` tool.
