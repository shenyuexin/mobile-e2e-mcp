# Phase 06 Plan 15

## Goal

### Problem
Canonical skills existed, but MCP internal failure handling still did not automatically use their routing logic.

### Expected Outcome
- [x] `suggest_known_remediation` now returns built-in skill-guided remediation data.
- [x] Developers can get baseline/Android/iOS routing through the existing MCP chain without separate agent-side skill calls.

### Non-goals
- Building a full in-server skill runtime.
- Replacing the canonical skill files as repo truth.

## Strategy

Inject the validated readiness logic into the existing remediation chain by extending `suggest_known_remediation` rather than adding a new subsystem.
